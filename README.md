# SQL Data Analytics Project – Exploratory & Advanced Analysis with SQL

Welcome to my SQL Data Analytics Project! 🚀  
This project is built on top of my previous **SQL Data Warehouse Project**, where I designed a complete ETL pipeline and a star schema using the Medallion Architecture model.  
The **cleaned and modeled Gold Layer tables** from that project serve as the foundation for all analytics performed here.

The purpose of this project is to demonstrate how to perform real business analytics using SQL — starting with Exploratory Data Analysis (EDA) and progressing to more advanced analytical techniques.

---

## 🔗 Project Foundation – Using the Data Warehouse (Gold Layer)

This analytics project reuses the datasets and tables created in my previous project:

- ✔ Medallion Architecture (Bronze → Silver → Gold)  
- ✔ ETL from CSV data sources  
- ✔ Star Schema (fact & dimension tables)

The **Gold Layer** (business-ready star schema) was used as the analytical dataset for all SQL queries in this repository.

---

## 📊 Project Overview – What This Project Covers

This project follows a complete analytics pipeline:

---

### 🔍 **1. Exploratory Data Analysis (EDA)**  
Understanding the data model and its structure:

- **Database Exploration**  
  Tables, keys, relationships, row counts  
- **Dimension Exploration**  
  Customers, products, regions, categories  
- **Date Exploration**  
  Year, month, quarter, weekday extractions  
- **Measures Exploration**  
  Revenue, orders, customers, key KPIs  
- **Magnitude Analysis**  
  Comparing categories, regions, or segments  
- **Ranking**  
  Top-N / Bottom-N reports (e.g., best products)

---

### 📈 **2. Advanced Analytics**  
More complex business insights using SQL:

- **Change Over Time (Trends)**  
  Time series, growth rates, month-over-month analysis  
- **Cumulative Analysis**  
  Running totals (revenue, orders)  
- **Performance Analysis**  
  Actuals vs. targets, regional performance  
- **Part-to-Whole Analysis**  
  Revenue share by category, region, etc.  
- **Data Segmentation**  
  Customer/product segmentation based on behavior  
- **Reporting**  
  Creating reusable analytical views  

These follow the learning structure from *Data with Baraa*, whose teaching inspired this project.
