# SQL Data Analytics Projekt

Dieses Repository enthält mein SQL-Analyseprojekt, das ich im Rahmen meiner SQL-Lernreise aufgebaut habe.  
Das Projekt orientiert sich an der Lernmethodik von **Baraa (Data with Baraa)** und deckt sowohl **Explorative Datenanalyse (EDA)** als auch **Advanced Analytics** ab.

Das Ziel des Projekts ist es, mithilfe von SQL echte Business-Analysen zu erstellen.  
Ich durchlaufe zwei Hauptphasen:

                                1. **Explorative Datenanalyse (EDA)** – Verständnis der Datenbank, Tabellen, Dimensionen und Kennzahlen.
                                2. **Fortgeschrittene Analytics** – Trendanalysen, Performance, kumulative Analysen, Segmente & Reporting.

Im Repository befinden sich alle SQL-Abfragen, die ich selbst geschrieben und ausgeführt habe .
